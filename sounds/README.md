# Sounds (optional)

Every sound effect is synthesised in the browser, so this folder can stay empty.

To use your own audio, add a file here and map it in `js/config.js`:

```js
export const SOUND_FILES = {
  reveal: 'sounds/reveal.mp3',
  pop: 'sounds/pop.wav',
};
```

Sound names: `click`, `open`, `poke`, `rattle`, `whoosh`, `dim`, `heartbeat`, `charge`, `pop`, `flash`, `flip`, `sparkle`, `glitch`, `reveal`, `secret`.
